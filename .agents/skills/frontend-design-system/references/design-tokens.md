# Design Tokens & Palette Reference

## Modern Dark Theme Tokens
- Background: `#0B0F17` (Deep Slate / Obsidian)
- Surface / Cards: `#131B2E` with border `#1E293B`
- Primary Accent: `#6366F1` (Indigo 500) / Hover `#4F46E5`
- Secondary Accent: `#10B981` (Emerald 500)
- Text Primary: `#F8FAFC` (Slate 50)
- Text Secondary: `#94A3B8` (Slate 400)
- Text Muted: `#64748B` (Slate 500)

## Micro-Interaction Rules
- Button transitions: `transition: all 0.15s cubic-bezier(0.4, 0, 0.2, 1);`
- Active state: `transform: scale(0.98);`
- Card hover: Subtle border glow + 2px translateY.
