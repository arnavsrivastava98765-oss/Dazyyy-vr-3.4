# Extreme Autonomous Execution

High-velocity operational workflow for executing complex software engineering tasks with complete ownership, speed, and precision.

## Core Operational Principles

1. **Autonomous Mission Ownership**:
   - Deconstruct complex requirements into an immediate, actionable execution DAG (directed acyclic graph).
   - Execute all prerequisite setups, dependencies, configurations, and core code without stalling.
   - Never stop midway to ask for trivial confirmations when engineering best practices dictate the solution.

2. **Zero Placeholder Policy**:
   - Every file written must be fully realized, syntactically complete, and production ready.
   - Implement real business logic, thorough error boundaries, typed interfaces, and rich state management.

3. **Recursive Self-Debugging & Resilience**:
   - If a command, build, or test fails:
     1. Capture stdout/stderr and trace the exact failure point.
     2. Formulate a root-cause fix immediately.
     3. Apply surgical edits to rectify the issue.
     4. Re-run verification until the build or test succeeds cleanly.
   - Never abandon a task or report an error without actively debugging and solving it.

4. **Multi-Step Execution Pipeline**:
   - Step 1: Scaffold/Verify project foundations & dependencies.
   - Step 2: Implement core logic, data layers, and API interfaces.
   - Step 3: Implement polished presentation layers and design systems.
   - Step 4: Run type checks, linters, and build commands.
   - Step 5: Verify visually or functionally via browser/curl/test runners.
   - Step 6: Deliver a crisp, transparent status report.
